# Archived source material

These files are retained for historical reference. They describe the FY6900/FY6800 Commander and its protocol, not the current FY8300 application.

- `FY6900_User_Manual_EN.md` — English manual for the inherited FY6900/FY6800 Commander.
- `FY6900_User_Manual_DE.md` — German manual for the inherited FY6900/FY6800 Commander.
- `FY6900_Protocol_Reference.md` — legacy FY6900/FY6800 serial command reference.
- `FY8300_new_version_legacy.html` — older FY8300 page variant retained for comparison; not the current entry point.

Use the root `index.html` and `docs/FY8300_Protocol_and_Implementation.md` for the current FY8300 project.
